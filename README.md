# Rinah Multi-Services | E-Commerce Store

E-commerce website for Rinah Multi-Services, an online store selling 
custom apparel (polos, t-shirts) with multiple fabric weights and 
pricing tiers.

🔗 Live site: [rinah.sdimada.com](https://rinah.sdimada.com)

## Features

- Product catalog with detailed listings
- Real-time pricing display
- Working shopping cart system
- Responsive, mobile-friendly design

## Tech Stack

- *Front-end:* Vue.js
- *Back-end:* Laravel
- *Database:* MySQL

## About

This project was designed and developed by me as founder of Rinah 
Multi-Services, covering the full process from UI/UX design to 
back-end logic and deployment.
